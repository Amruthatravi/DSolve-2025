## 💡 Project Idea
[Our project aims to reduce the number of buses arrived at the same stop simultaneously though it have been departed from correct time.This can be due to traffic or any ther issue and this need to be avoided.We have used AI to avoid bus bunking problems on a real time basis.By optimising the time the website will give the feedback as the 1st bus is late by how much minutes and the predicted time of arrival.]

## ✨ Key Features
- 🔍 Feature 1: [Opyimise the time using AI and we have trained a model named prophet using a dataset given to it in the format of date time of arrival predicted and it actually reached. ]
- ⚡ Feature 2: [Return how much minutes is the bus late so it can be known to the 2nd bus drivers and the passengers through the website that the 1st bus is late. ] 
- 🛡️ Feature 3: [We have used plolty for drawing the graph. ]
